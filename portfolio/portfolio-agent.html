Portfolio Agent Automated Rebalancing

An agentic rebalancer that reads a holdings spreadsheet, pulls end-of-day prices, recomputes your equity/income split to hit a target ratio, updates the sheet, and finishes with a push notification and a summary email draft.

View on GitHub

01 · Problem

Problem Statement

The Challenge

Keeping an investment portfolio at a target equity/income ratio means repeatedly checking market prices, recalculating quantities, and editing a spreadsheet by hand. This becomes a tedious, error-prone ritual every time the market moves.

Why It Matters

Manual rebalancing is slow and easy to get wrong — portfolios drift from their intended risk profile and rebalancing windows get missed entirely. An agent that does the whole job in minutes keeps the portfolio on target with full auditability.

Goals

  • Pull the latest end-of-day prices for all held tickers automatically.
  • Update the price and new-quantity columns in the sheet.
  • Verify the target ratio is met and confirm with a notification + email draft.

02 · Design

System Architecture

How It Works

  1. A web form captures the target equity/income ratio and starts the agent.
  2. The agent reads the portfolio sheet and updates the Price column with fresh end-of-day quotes from Marketstack.
  3. It computes new quantities to hit the ratio, writes them to the rebalancing table, re-checks the balance, then drafts a Gmail summary and sends a Pushover notification.

Tech Stack

  • AI / LLM — Google Gemini
  • Data — Google Sheets (read + update tools)
  • Market Data — Marketstack EoD API
  • Notifications / Email — Pushover, Gmail draft

04 · Process

Standard Operating Procedure (SOP)

The repeatable process used to build and run the Portfolio Agent.

01

Configure the Agent & Tools

Wire the agent to Google Sheets (read plus two update operations), Marketstack, Gmail, and Pushover, then encode the 7-step execution plan in the system prompt. This step defines everything the agent is allowed to do.

02

Run & Verify the Rebalance

Submit the target equity/income ratio on the web form and watch the agent read prices, update the sheet, and re-check the balance. Confirm the success notification and the drafted summary email that reports the changes and improvements.

Notes & Caveats

The agent drafts the email rather than sending it, so a human reviews the summary before it goes out. Re-run the workflow whenever you want a fresh rebalance — each run overwrites the Price and New Quantity columns.
